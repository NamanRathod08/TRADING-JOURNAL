# Ledgerly

A browser-first equity trading journal. Trade data is stored in localStorage in the user's browser, making it private and immediately usable without an account.

## Run locally

Open `index.html` in a modern browser, or serve the folder with any static-file server.

## Features

- Equity-only manual trade entry with long/short P&L, P&L percentage, and holding-time calculations
- Tagged setups and strategy-level P&L analysis
- Sortable/filterable trade history plus CSV import and export
- Equity curve, win rate, average win/loss, best/worst trade, profit factor
- Journal reflections for trade rationale and lessons
